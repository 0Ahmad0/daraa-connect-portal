حزمة بوابة الإنترنت - محافظة درعا
=================================

هذه الحزمة لا تُرفع وحدها كمجلد Hotspot كامل.
يجب دمجها مع مجلد hotspot الأصلي الذي أنشأه الراوتر حتى تبقى ملفات
md5.js و api.json و alogin.html و status.html و logout.html موجودة.

المتطلبات
---------
1. راوتر MikroTik عليه HotSpot يعمل أصلاً.
2. برنامج WinBox واتصال إداري بالراوتر.
3. حساب تجريبي معروف الاسم وكلمة المرور.

خطوات التركيب
-------------
1. افتح WinBox ثم Files.
2. نزّل مجلد hotspot الموجود في الراوتر إلى الكمبيوتر كنسخة احتياطية.
3. انسخ المجلد على الكمبيوتر وسمِّ النسخة hotspot-daraa.
4. افتح هذه الحزمة وانسخ login.html ومجلد assets إلى داخل hotspot-daraa.
5. وافق على استبدال login.html فقط.
6. تأكد أن hotspot-daraa يحتوي على الأقل:
   - login.html
   - md5.js
   - api.json (في RouterOS الحديث)
   - alogin.html
   - status.html
   - logout.html
   - assets/
7. من WinBox > Files ارفع مجلد hotspot-daraa كاملاً إلى الراوتر.
8. افتح IP > Hotspot > Server Profiles.
9. افتح البروفايل المستخدم وسجّل قيمة HTML Directory الحالية قبل تغييرها.
10. غيّر HTML Directory إلى مسار hotspot-daraa المرفوع.
    قد يكون المسار hotspot-daraa أو flash/hotspot-daraa بحسب طراز الراوتر ومكان التخزين.
11. في تبويب Login أبقِ http-chap و cookie مفعّلين.
12. اضغط Apply ثم OK.

طريقة التجربة
-------------
1. من IP > Hotspot > Users أنشئ حساباً تجريبياً مؤقتاً.
2. على هاتف ليس لديه جلسة قديمة: انسَ شبكة Wi-Fi ثم اتصل بها من جديد.
3. انتظر ظهور نافذة تسجيل الدخول. إذا لم تظهر، افتح عنوان HTTP عادياً.
4. أدخل بيانات الحساب التجريبي.
5. يجب أن يفتح الإنترنت، ويظهر المستخدم في IP > Hotspot > Active.
6. جرّب كلمة مرور خاطئة وتأكد من ظهور رسالة خطأ.
7. جرّب Android وiPhone إن أمكن.

الرجوع السريع عند حدوث مشكلة
-----------------------------
ارجع إلى IP > Hotspot > Server Profiles وأعد قيمة HTML Directory القديمة.
لا تحذف مجلد hotspot الأصلي ولا تغيّر إعدادات الشبكة أو الـ Firewall أثناء اختبار التصميم.

ملاحظات مهمة
------------
- لا تفعّل http-pap على شبكة HTTP؛ كلمة المرور تنتقل كنص واضح.
- login.html في هذه الحزمة يدعم HTTP-CHAP ويعتمد على md5.js الأصلي من الراوتر.
- إذا لم يكن HotSpot معداً أصلاً، لا تشغّل Setup عشوائياً: يجب أن يختار الفني واجهة LAN/bridge الصحيحة.
- أرسل صورة System > Resources وصورة Server Profiles > Login عند ظهور مشكلة.
