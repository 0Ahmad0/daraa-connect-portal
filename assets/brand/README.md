# ملفات الهوية

- `logo.svg`: الشعار الرسمي الذهبي.
- `ornament.svg`: الزخرفة الأفقية المستخدمة داخل بطاقة الدخول.
- `background.png`: نسخة محسنة من خلفية الهوية للاستخدام على الشبكات البطيئة.
- `flag.svg`: أيقونة العلم.
- ألوان الهوية موجودة كمتغيرات في أعلى `assets/css/main.css` لتعديلها من مكان واحد.
